# Zelatan Cell — Frontend (React + Vite)

Antarmuka pelanggan dan admin Zelatan Cell. Dokumentasi lengkap ada di
[README utama](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173, /api diteruskan ke backend di :8080
npm run build   # hasil di dist/, salin ke backend/src/main/resources/static/
```

Butuh Node.js 20.19+ atau 22.12+, dan backend berjalan di port 8080.
